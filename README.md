# Arshad Work Assistant

Web app ringkas untuk semak dan urus order penghantaran.

> Jangan simpan nama customer, nombor telefon atau alamat dalam repo ini kerana repo ini public.

## Setup GitHub token dalam app

1. Buka app dan tekan **GitHub**.
2. Cipta Fine-grained personal access token yang hanya boleh akses repo ini.
3. Tetapkan permission **Contents: Read and write**.
4. Paste token pada browser yang digunakan. Token tidak disimpan dalam kod atau repo.
